# Plantsy

A React app for browsing and managing a plant shop's inventory.

![Plantsy app screenshot](docs/screenshot.png)

## Description
Plantsy loads plants from a local json-server backend and lets you add
new plants, mark them as sold out, and search by name.

## Features
- View all plants on page load
- Add a new plant using the form (saved via POST)
- Mark a plant as "Out of Stock"
- Search plants by name

## Installation
1. Clone the repo: `git clone <your-repo-url>`
2. Install dependencies: `npm install`
3. Start the backend: `npm run server` (runs on http://localhost:6001)
4. In another terminal, start the app: `npm run dev`

## Usage
Open the local URL shown by Vite. Use the form to add a plant, the
button on a card to mark it sold out, and the search bar to filter.

## Technologies
React, Vite, json-server
